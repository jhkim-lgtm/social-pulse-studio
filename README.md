# Pulse — Social Content OS 데모

터지는 콘텐츠를 발견하고, 우리 브랜드에 맞게 제작·예약·분석하는 정적 SPA 프로토타입입니다. Toss 스타일의 여백과 정보 위계를 참고해 라이트/다크 모드를 모두 지원합니다.

## 실행

별도 빌드나 패키지 설치가 필요하지 않습니다.

```bash
python3 -m http.server 4173 --directory social-pulse-studio
```

브라우저에서 `http://localhost:4173`을 엽니다. `index.html`을 직접 열어도 대부분의 기능을 사용할 수 있습니다.

## 구현된 흐름

- Overview: 실시간 신호, 운영 보드, 성과 요약
- DISCOVERY: **1%CLUB이 실제 올릴 수 있는 버티컬(패션·뷰티·호텔·럭셔리 라이프·럭셔리 브랜드·자동차·F&B) 중심의 외부 급상승 실데이터** — ① IG 버티컬 계정 19곳의 분당 좋아요 급상승 (실측 차분) ② 글로벌 시그널: TikTok Creative Center JP·US 주간 영상 + Douyin 热点榜 + KR 해시태그. 목적: 터지는 콘텐츠를 빠르게 파악 → 소싱/기획 → 트위스트해서 자사 채널 콘텐츠로 재제작
- Studio: Discovery에서 선택한 **레퍼런스의 실제 영상·이미지가 캔버스에 로드**되어 그 위에서 트위스트 시안 작업 (영상은 릴스 포맷 자동 전환, 원본 요소 그대로 게시 전 권리 확인 필요)
- Publish: 채널·날짜·시간·본문을 설정한 데모 예약, 7일 캘린더와 대기열
- Analytics: 도달/참여 SVG 차트, 포맷 기여도, 콘텐츠 비교
- Ads: 예산/성과 요약과 광고 캠페인 초안
- Connector registry: Connected, Missing scope, Demo 연결 상태
- `localStorage`: 테마, 선택 콘텐츠, 타겟 소스, Studio 상태, 데모 예약, 광고 초안 유지
- 반응형: 데스크톱 사이드바, 태블릿 축소 메뉴, 모바일 하단 내비게이션

## 데이터와 권리 범위

DISCOVERY는 **외부 플랫폼 공식 트렌드 보드의 실데이터**로 동작합니다.

| 소스 | 내용 | 갱신 주기 |
|------|------|-----------|
| IG 버티컬 계정 19곳 (`tools/ig_sources.json`) | 패션·뷰티·호텔·럭셔리 라이프·럭셔리 브랜드·자동차·F&B 버티컬별 큐레이션 계정. Business Discovery API로 최근 게시물 좋아요 스냅샷 → 재실행 시 차분으로 **1분당 좋아요 증가 실측** (첫 실행은 게시 후 평균 폴백). 계정당 급상승 TOP 2, 1위 항목은 릴스 mp4까지 | 실행할 때마다 (2분~12시간 간격 차분) |
| TikTok Creative Center (JP·US) | 주간 급상승 크리에이터 영상 — 조회수·팔로워·토픽 + 실제 미리보기 mp4 | 주간 (수집 시점 스냅샷) |
| Douyin 热点榜 | 실시간 핫토픽 TOP — 热度·연관 영상 수·커버 | 실시간 보드의 수집 시점 스냅샷 |
| TikTok CC KR 해시태그 | 한국 주간 급상승 해시태그 — 순위·게시물·조회수 (비로그인 TOP 3) | 주간 |

갱신: `python3 tools/fetch_trending.py` 재실행 → `assets/trending-content.json` / `.js` 재생성, 미디어는 `assets/trending/`에 로컬 저장 (헤드리스 Chrome + `websocket-client` + ffmpeg 필요). 부분 갱신은 `--only ig` (약 30초, IG 좋아요 차분만 갱신) / `--only douyin` 등 — 나머지 그룹은 기존 스냅샷 유지.

Viral score는 세트 내 조회·热度 상대 순위(76~99 정규화)로 계산한 파생 지표입니다. YouTube 트렌딩 페이지는 2025-07 폐지되어 소스에서 제외했고, Playboard 등 국내 집계 사이트는 봇 차단으로 제외했습니다.

**권리**: 모든 Discovery 항목은 외부 크리에이터의 콘텐츠(reference-only)입니다. 훅·구조·포맷을 분석해 트위스트 재제작하는 용도로 캔버스에 로드하며, 원본 이미지·영상·음원을 그대로 게시하려면 사전 권리 확인이 필요합니다 (CONTENT_POLICY.md 참조).

예약 및 광고 기능은 실제 외부 요청을 전송하지 않습니다. 화면에서도 각각 `데모 예약`, `광고 초안`으로 표시됩니다. 실제 서비스 전환에는 플랫폼별 공식 API 승인, OAuth 권한 동의, 미디어 스토리지, 예약 작업 서버, 웹훅 및 광고 계정 검증이 필요합니다.
