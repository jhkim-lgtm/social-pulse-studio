# Pulse — Social Content OS 데모

터지는 콘텐츠를 발견하고, 우리 브랜드에 맞게 제작·예약·분석하는 정적 SPA 프로토타입입니다. Toss 스타일의 여백과 정보 위계를 참고해 라이트/다크 모드를 모두 지원합니다.

## 실행

별도 빌드나 패키지 설치가 필요하지 않습니다.

```bash
python3 -m http.server 4173 --directory social-pulse-studio
```

브라우저에서 `http://localhost:4173`을 엽니다. `index.html`을 직접 열어도 대부분의 기능을 사용할 수 있습니다.

## 구현된 흐름

- Overview: 실시간 신호, 운영 보드, 성과 요약
- DISCOVERY: Instagram, TikTok, YouTube Shorts, Douyin 샘플 콘텐츠 필터·검색·정렬
- Studio: 선택한 콘텐츠의 구조를 참고한 피드/릴스 편집, 톤앤매너 및 샘플 카피 생성
- Publish: 채널·날짜·시간·본문을 설정한 데모 예약, 7일 캘린더와 대기열
- Analytics: 도달/참여 SVG 차트, 포맷 기여도, 콘텐츠 비교
- Ads: 예산/성과 요약과 광고 캠페인 초안
- Connector registry: Connected, Missing scope, Demo 연결 상태
- `localStorage`: 테마, 선택 콘텐츠, 타겟 소스, Studio 상태, 데모 예약, 광고 초안 유지
- 반응형: 데스크톱 사이드바, 태블릿 축소 메뉴, 모바일 하단 내비게이션

## 데이터와 권리 범위

이 사이트는 공개 API 키가 없는 **정적 라이브 데모**입니다. 표시되는 계정명, 수치, 급상승 점수, 성과 및 예상치는 기능 체험을 위한 샘플이며 실제 플랫폼 데이터가 아닙니다.

DISCOVERY의 `좋아요/분`은 제품 설계상 1분 간격 metric snapshot 차분으로 계산한다는 가정을 보여줍니다. 각 카드에 샘플 출처, 10분 관측 구간, 마지막 갱신, 권리 확인 배지를 표시합니다.

경쟁 콘텐츠는 아이디어와 구조 분석용이며 원본 이미지·영상·음원을 재사용하면 안 됩니다. 실제 제작·게시 전에 저작권, 초상권, 음원 라이선스 및 각 플랫폼 정책을 확인해야 합니다.

예약 및 광고 기능은 실제 외부 요청을 전송하지 않습니다. 화면에서도 각각 `데모 예약`, `광고 초안`으로 표시됩니다. 실제 서비스 전환에는 플랫폼별 공식 API 승인, OAuth 권한 동의, 미디어 스토리지, 예약 작업 서버, 웹훅 및 광고 계정 검증이 필요합니다.
